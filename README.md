# ecommerce-sales-analysis
E-commerce sales analysis using SQL and Excel, with an interactive dashboard and business insights.

## Project Overview
Analysis of 5,000 e-commerce transactions using MySQL and Excel to evaluate sales, profitability, customer behavior, and regional performance, through an interactive Excel dashboard and a detailed business report. The analysis aims to support inventory planning, pricing, and marketing decisions.

## Data used
- <a href="https://github.com/AKRAMHOUSSA/ecommerce-sales-analysis/blob/main/Ecommerce_Sales_Data_2024_2025.csv">Dataset_sales

## Business Questions
- Which product generated the highest revenue? 
- How loyal are the store's customers based on purchasing behavior? 
- Which region and city generated the highest revenue and sales quantity? 
- Which category and sub-category generated the highest sales and profit? 
- Which payment mode is most frequently used by customers? 
- How do monthly sales and profit change over time? 
- Is there a relationship between discount and sales revenue across sub-categories?

  ## Tools Used
- MySQL
- Microsoft Excel
- Power Pivot
- DAX

## Process
1. Data Cleaning and Validation using MySQL
2. SQL Analysis and Aggregation
3. Business Insights and Recommendations
4. Interactive Dashboard Development in Excel
5. Final Report Preparation
